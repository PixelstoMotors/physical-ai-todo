# フィジカルAIが社会実装される前に解くべき課題

放置すればフィジカルAI・ロボティクスの社会実装そのものが頓挫する構造的な課題を、
技術・制度・体験の3つの視点を横断して抽出・整理した課題地図（評価版プロトタイプ）。

## 構成

```
index.html        トップ（9分類・36課題カード・規制制度索引）
map.html          課題マップ（関連ネットワーク図）
sources.html      出典・データ集（発行主体別 45件）
categories/       カテゴリ別一覧ページ x9
issues/           課題詳細 x36（.md が編集の正、.html は生成物）
assets/style.css  共通スタイル（全ページここで一元管理）
```

## 更新の流れ

詳細ページの本文は `issues/*.md` を編集し、生成スクリプトで `.html` を再生成する。
カード情報（緊急度・深刻度・分類など）は frontmatter が唯一の正。

## ディスクレーマー

生成AIによる制作・評価版。数値・規制の記述は一次出典での確認前のものを含む。
特定のメーカー・エコシステムの立場はとらない。
